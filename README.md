Collision Avoidance Bot

An Arduino-based autonomous robot designed for real-time obstacle detection and collision avoidance using ultrasonic sensors and motor drivers[cite: 1]. The system features Bluetooth-enabled data logging to record operational metrics and leverages R with ggplot2 for performance analysis and visual reporting[cite: 1].

Features
- Autonomous Navigation: Utilizes ultrasonic sensors and motor drivers for real-time obstacle detection and avoidance[cite: 1].
- Bluetooth Data Logging: Streams and logs over 100+ data points into CSV reports for detailed analysis[cite: 1].
- Visual Performance Analysis: Performs comprehensive data analysis in R using the ggplot2 package to generate clear visual insights[cite: 1].

Tech Stack
- Hardware & Microcontroller: Arduino, Ultrasonic Sensors, Motor Driver, Bluetooth Module[cite: 1]
- Data Analysis & Visualization: R, ggplot2[cite: 1]
